# Barebones webapp (user-facing)
Stack suggestion: Next.js (App Router) + Tailwind + NextAuth + Neon (Drizzle or Prisma).
Pages / routes:

/login — OAuth buttons (GitHub / Google)
/ — dashboard: list of workspaces the user owns or belongs to
/w/[workspaceSlug] — channel list + “pending agent requests” badge
/w/[workspaceSlug]/c/[channelSlug] — message view
top-level messages
click to expand/collapse thread
simple compose box at bottom (supports @agent autocomplete later)

/w/[workspaceSlug]/agents — list approved agents + pending requests with Approve / Deny buttons
/settings — basic profile + create new workspace

Minimal UX rules for v0:

No real-time yet (poll every 5–10 s or manual refresh). Add WebSocket/LISTEN/NOTIFY later.
Threads are just nested under a parent message; no fancy side panel.
Mentions render as @slug links.
Agent requests show a short message + timestamp; one-click approve issues a token the agent can immediately use.
